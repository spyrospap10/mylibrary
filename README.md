# 📚 MyLibrary - Android Library Management App

Μια native Android εφαρμογή για την πλήρη διαχείριση μιας βιβλιοθήκης. Το σύστημα υποστηρίζει διπλό ρόλο χρηστών (Διαχειριστές και Μέλη) και αξιοποιεί μια υβριδική αρχιτεκτονική βάσεων δεδομένων, συνδυάζοντας τοπική αποθήκευση και Cloud συγχρονισμό για βέλτιστη απόδοση.

## 🛠 Τεχνολογίες & Αρχιτεκτονική (Tech Stack)
* **Γλώσσα Προγραμματισμού:** Kotlin
* **Διπλή Βάση Δεδομένων:**
  * **SQLite:** Για ταχύτατη τοπική αποθήκευση και offline προσβασιμότητα σε βασικά δεδομένα.
  * **Firebase Firestore:** NoSQL cloud βάση για συγχρονισμό δεδομένων σε πραγματικό χρόνο (π.χ. διαθεσιμότητα βιβλίων, ειδοποιήσεις).
* **UI/UX:** XML Layouts, Material Design Components, RecyclerViews με Custom Adapters (π.χ. Carousel προβολή βιβλίων).
* **Navigation:** Android Jetpack Navigation (Fragments) και Navigation Drawer.

## ✨ Βασικές Λειτουργίες

### 👤 Για τα Μέλη (Users):
* **Είσοδος/Εγγραφή:** Ο χρήστης κάνει απλή είσοδο με username και κωδικό (μοναδικά για κάθε χρήστη) ή εγγραφή αν έρχεται στην εφαρμογή για πρώτη φορά.
* **Πληροφορίες:** Η αρχική σελίδα είναι ένα μεγάλο και όμορφο carousel με φωτογραφίες της βιβλιοθήκης και με διάφορες πληροφορίες. 
* **Κατάλογος Βιβλίων:** Περιήγηση στη συλλογή των βιβλίων και δυνατότητα σύνθετου φιλτραρίσματος (ανά κατηγορία, συγγραφέα, είδος, απόθεμα κ.λπ.).
* **Δανεισμός & Επιστροφές:** Αίτημα δανεισμού βιβλίων (αν υπάρχει διαθεσιμότητα). Το κάθε μέλος μπορεί να κάνει μέχρι έναν δανεισμό κάθε φορά. Αν θέλει παραπάνω βιβλία θα πρέπει να κάνει συνδρομή. Ο χρήστης μπορεί να κάνει παραλαβή από κατάστημα ή να γράψει την διεύθυνση του για να το λάβει στο σπίτι του. Στην συνέχεια ο δανεισμός αυτός θα εμφανίζεται αυτόματα στην λίστα δανεισμών με την ημερομηνία.
* **Συνδρομές (Subscriptions):** Απεριόριστοι δανεισμοί για όσο κρατήσει ο δανεισμός. Δυνατότητα δωρεάν συνδρομής για έναν χρόνο για τους φοιτητές του ΔΙΠΑΕ μέσω αυθεντικοποίησης λογαριασμού στο moodle των φοιτητών. 
* **Ειδοποιήσεις:** Λήψη γνωστοποιήσεων τόσο στην εφαρμογή όσο και στο κινητό (π.χ. λήξη προθεσμίας επιστροφής βιβλίου, επιτυχής επιστροφή βιβλίου ή λήξη δανεισμού).
* **Λογαριασμός:** Δυνατότητα αλλαγής προσωπικών στοιχείων και κωδικών.

### 🛡️ Για τους Διαχειριστές (Admins):
Το προσωπικό της βιβλιοθήκης έχει πρόσβαση σε ένα εξειδικευμένο διαχειριστικό πάνελ:
* **Είσοδος/Εγγραφή:** Ο χρήστης κάνει απλή είσοδο με username και κωδικό (μοναδικά για κάθε χρήστη) ή εγγραφή αν έρχεται στην εφαρμογή για πρώτη φορά. Πληκτρολογεί επίσης έναν επιπλέον κωδικό διαχειριστή, τον οποίο δεν γνωρίζουν οι χρήστες.
* **Διαχείριση Χρηστών:** Προβολή λίστας μελών και διαχειριστών καθώς και όλων των στοιχείων τους.
* **Διαχείριση Βιβλίων:** Προβολή, προσθήκη, αφαίρεση, επεξεργασία και διαγραφή βιβλίων (μέσω ειδικών Dialogs).
* **Διαχείριση Δανεισμών:** Προβολή όλων των ενεργών δανεισμών. Κουμπί επιστροφή δίπλα από κάθε δανεισμό που το πατάει ο διαχειριστής μόλις επιστραφεί το βιβλίο. Μόλις πατηθεί το κουμπί επιστροφή, αυτόματα ο δανεισμός φεύγει και από την λίστα του χρήστη και πηγαίνει στο ιστορικό δανεισμών.
* **Στατιστικά (Dashboard):** Προβολή δεδομένων (π.χ. τα πιο δημοφιλή βιβλία, ενεργοί δανεισμοί) μέσω οπτικοποιημένων στατιστικών (`StatisticsFragment`).

* **Για όλους:** Κουμπί Αποσύνδεσης για όλους τους χρήστες και επιστροφή στο σημείο του login. Επίσης σε κάθε χρήστη φαίνεται κάτω κάτω το username του όταν είναι συνδεδεμένος.

## 🚀 Εγκατάσταση (Local Development)

Λόγω της χρήσης Firebase, το project απαιτεί το δικό σας αρχείο ρυθμίσεων για να λειτουργήσει.

* 1. Κάντε clone το repository:
   ```bash
   git clone [https://github.com/ΤΟ_USERNAME_ΣΑΣ/MyLibrary.git](https://github.com/ΤΟ_USERNAME_ΣΑΣ/MyLibrary.git)
* 2. Ανοίξτε το project στο Android Studio.
* 3. Δημιουργήστε ένα νέο project στο Firebase Console.
* 4. Ενεργοποιήστε το Firestore Database και το Authentication (αν χρησιμοποιείται).
* 5. Κατεβάστε το δικό σας αρχείο google-services.json από το Firebase και τοποθετήστε το μέσα στον φάκελο app/ του project.
* 6. Κάντε Sync Project with Gradle Files και τρέξτε την εφαρμογή σε Emulator ή φυσική συσκευή.

### 🔒 Ασφάλεια Δεδομένων
Τα ευαίσθητα δεδομένα σύνδεσης με τη βάση δεδομένων του Firebase (google-services.json) έχουν εξαιρεθεί από το δημόσιο αποθετήριο (μέσω .gitignore) για λόγους ασφαλείας. Η πρόσβαση στα δεδομένα του Firestore προστατεύεται μέσω Firebase Security Rules, τα οποία διαχωρίζουν τα δικαιώματα ανάγνωσης/εγγραφής ανάλογα με τον ρόλο του χρήστη (Admin/User).
